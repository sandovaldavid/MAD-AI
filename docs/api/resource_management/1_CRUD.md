# Endpoints CRUD (Operaciones Estándar)

Incluye todos los endpoints de creación, lectura, actualización y eliminación.

## Ausencias
- GET/POST `/api/v1/absences/`
- GET/PUT/DELETE `/api/v1/absences/{id}/`
<!--  -->
## Recursos Humanos
- GET/POST `/api/v1/resource_management/human-resources/`
- GET/PUT/PATCH/DELETE `/api/v1/resource_management/human-resources/{resource}/`

## Recursos Materiales
- GET/POST `/api/v1/resource_management/material-resources/`
- GET/PUT/PATCH/DELETE `/api/v1/resource_management/material-resources/{resource}/`

## Tipos de Recurso
- GET/POST `/api/v1/resource_management/resource-types/`
- GET/PUT/PATCH/DELETE `/api/v1/resource_management/resource-types/{id}/`

## Recursos Generales
- GET/POST `/api/v1/resource_management/resources/`
- GET/PUT/PATCH/DELETE `/api/v1/resource_management/resources/{id}/`
