# Endpoints de Operaciones Masivas

Manejan múltiples registros en una sola operación.

- POST `/api/v1/absences/bulk-approve/`
- POST `/api/v1/absences/bulk-create/`
- POST `/api/v1/resource_management/availabilities/bulk-operations/`
- POST `/api/v1/resource_management/resource-types/bulk-update/`
- POST `/api/v1/resource_management/resources/bulk-create/`
